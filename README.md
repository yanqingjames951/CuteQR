# CuteQR

一个简洁、美观、功能丰富的二维码生成和扫描应用。

## 功能特点

### 1. 二维码生成
- [x] 支持多种数据类型：
  - 文本
  - 网址 (URL)
  - 联系人信息 (vCard)
  - Wi-Fi 配置
  - 短信
  - 电话号码
  - 邮件
  - 日历事件
  - 位置信息
- [x] 自定义样式：
  - 方块样式
  - 圆点样式
  - 圆角样式
  - 自定义颜色
  - Logo 添加（支持大小和圆角调整）

### 2. 历史记录
- [x] 自动保存生成记录
- [x] 按类型筛选
- [x] 搜索功能
- [x] 收藏功能
- [x] 批量操作
- [x] 分享功能

### 3. 扫描功能
- [x] 相机扫描
- [x] 图片识别
- [x] 扫描历史
- [x] 快速操作（复制、分享等）

## 系统要求

- iOS 15.0 或更高版本
- Xcode 15 或更高版本
- Swift 5.9 或更高版本
- 启用 iCloud 同步需要有效的 Apple ID

## 安装说明

1. 克隆仓库
2. 打开 CuteQR.xcodeproj
3. 选择目标设备或模拟器
4. 构建并运行应用

## iCloud 同步功能使用说明

1. 确保您的设备已登录 Apple ID 并启用 iCloud
2. 在应用设置中开启"启用 iCloud 同步"选项
3. 首次启用后，应用将自动从云端获取数据并与本地数据合并
4. 您可以随时通过"立即同步"按钮手动触发同步
5. 同步方向可选择"从云端获取"或"上传到云端"
6. 同步状态和上次同步时间将显示在设置页面
