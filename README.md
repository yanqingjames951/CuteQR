# CuteQR

一个简洁、美观、功能丰富的二维码生成和扫描应用。

## 功能特点

### 1. 二维码生成
- [x] 支持多种数据类型：
  - 文本
  - 网址 (URL)
  - 联系人信息 (vCard)
  - Wi-Fi 配置
  - 短信
  - 电话号码
  - 邮件
  - 日历事件
  - 位置信息
- [x] 自定义样式：
  - 方块样式
  - 圆点样式
  - 圆角样式
  - 自定义颜色
  - Logo 添加（支持大小和圆角调整）

### 2. 历史记录
- [x] 自动保存生成记录
- [x] 按类型筛选
- [x] 搜索功能
- [x] 收藏功能
- [x] 批量操作
- [x] 分享功能

### 3. 扫描功能
- [x] 相机扫描
- [x] 图片识别
- [x] 扫描历史
- [x] 快速操作（复制、分享等）

## 技术栈

- **UI框架**: SwiftUI
- **架构模式**: Context7 (基于MVVM)
- **数据持久化**: UserDefaults, CloudKit
- **二维码生成**: CoreImage (CIFilter.qrCodeGenerator)
- **二维码扫描**: AVFoundation
- **图片处理**: UIKit, SwiftUI
- **依赖管理**: Swift Package Manager
- **版本控制**: Git
